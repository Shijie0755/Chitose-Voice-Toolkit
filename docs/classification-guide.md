# 人工分类标准

当前人工整理尚未完成，分类后的 WAV 和最终清单不会在本版本公开。

## 四个目录

### 能用（声音正常）

角色确定为千束，收音清楚，背景干扰轻微或没有明显干扰，适合成为主要训练数据。

### 能用（声音较高）

角色确定为千束，但音高、情绪或说话状态明显偏高。保留情绪差异，同时与正常声音分开，便于后续控制数据比例。

### 暂留（背景音或其他）

说话人很可能正确，但存在背景音乐、环境音、短促音效、轻微重叠、截断风险或其他需要进一步判断的问题。不要直接放进最终训练集。

### 不留

包括但不限于：

- 背景音乐或枪声等强干扰；
- 非千束声音；
- 多人重叠且无法分离；
- 严重混响、失真或截断；
- 文本和语音不对应；
- 其他会降低训练质量的情况。

## 推荐操作

1. 在磁盘上建立上述四个目录。
2. 在拖放分类器中为 A、B、C、D 依次绑定四个路径。
3. 一次试听一个 WAV，然后拖到对应卡片。
4. 分类完成前不要运行最终清单重建或全季训练。
5. 对“暂留”进行第二轮复核；不要因为降噪算法存在就默认所有干扰都能修复。
